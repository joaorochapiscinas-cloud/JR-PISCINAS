# JR Piscinas — site institucional

## Abrir o site
1. Extraia o ZIP.
2. Abra a pasta `jr-piscinas` no VS Code.
3. Abra `index.html` no navegador. Opcional: use a extensão Live Server.

## Personalizar antes de publicar
- No `index.html`, atualize telefone, endereço, horários e redes sociais conforme os dados reais.
- No `script.js`, altere `WHATSAPP_NUMBER` para o número da empresa, somente números com país e DDD (exemplo fictício: `5548999999999`).
- As fotos são carregadas do Unsplash e o Google Fonts é carregado online; é necessária internet para esses recursos.
- Ajuste serviços e textos de acordo com o que a JR Piscinas realmente oferece.

## Arquivos
- `index.html`: conteúdo e estrutura
- `style.css`: visual azul/aqua, responsividade e animações
- `script.js`: menu mobile, formulário de orçamento e animações

O conteúdo comercial é demonstrativo; substitua os dados de exemplo pelos dados verdadeiros da empresa.
